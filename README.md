# Guess The Number 2

Projekt zaliczeniowy z Programowania Obiektowego w C#.

Autor: Alicja Arczykowska

---

# Opis gry

Guess The Number 2 to rozbudowana wersja klasycznej gry „Zgadnij liczbę”.

Gracz wybiera poziom trudności i próbuje odgadnąć ukrytą liczbę w jak najmniejszej liczbie prób.

Gra zawiera:

- klasyczny tryb gry,
- tryb New Game Plus,
- Hall Of Fame,
- ustawienia,
- tryb zakładu,
- pomiar czasu gry.

---

# Funkcje gry

## Tryby gry

### Standard Game
Klasyczna wersja gry:
- liczba pozostaje taka sama przez całą rozgrywkę.

### New Game Plus
Rozszerzona wersja gry:
- co kilka prób ukryta liczba jest losowana ponownie.

---

# Poziomy trudności

- Easy → zakres 1–50
- Medium → zakres 1–100
- Hard → zakres 1–250

---

# Bet Mode

Przed rozpoczęciem gry gracz może wybrać tryb zakładu:
- ustawia maksymalną liczbę prób,
- po przekroczeniu limitu gracz przegrywa.

Opcję można wyłączyć w ustawieniach.

---

# Hall Of Fame

Gra zapisuje TOP 5 najlepszych wyników dla każdego poziomu trudności.

W rankingu wyświetlane są:
- nazwa gracza,
- liczba prób,
- czas gry,
- oznaczenie New Game Plus.

Wyniki sortowane są:
1. po liczbie prób,
2. po czasie gry.

---

# Ustawienia

W ustawieniach można:
- zmienić język gry (PL / EN),
- wyczyścić Hall Of Fame,
- włączyć lub wyłączyć pytanie o Bet Mode.
